# Sealed npm bootstrap sources

These six source modules generate the closed bootstrap embedded at
`crates/tirith/src/cli/npm_sealed_bootstrap.cjs`. Native admission owns task
permission, fresh artifact/policy decisions, retained descriptor identities,
confinement, process cleanup, output verification and publication. JavaScript
cannot supply those facts or enable the execution gate.

Use Python 3.10+ and Node 22.17+ on Linux or macOS. The resolver controls use
POSIX file URLs, matching the product's Linux contract. From the repository root:

```sh
python3 tools/npm-bootstrap/build-bootstrap.py --check
python3 tools/npm-bootstrap/test-build-bootstrap.py
node tools/npm-bootstrap/bootstrap-controls.cjs
node tools/npm-bootstrap/descriptor-source-controls.cjs
node tools/npm-bootstrap/resolver-controls.cjs
```

The paths above assume the repository working directory; the scripts themselves
resolve inputs relative to their source locations. They require no package
installation or network access. The generated **product** bootstrap separately
requires the pinned Node 26.7.0 / npm 11.19.0 Linux ARM64 runtime.

After a reviewed source change, regenerate deliberately with:

```sh
python3 tools/npm-bootstrap/build-bootstrap.py --write
```

`--check` does not write. It compares the generated bytes and digest manifest;
changes to either the modules, bundle or manifest fail the check. The builder
reads only six fixed files, refuses symlink modules, enforces a 128KiB output
limit and adds no timestamps or machine paths. The initial reviewed bundle is
SHA256 `41183108651b825e4712922f9056d1caf5766814f992167ac36fd200d9daa4d7`;
the generation regression deliberately binds those bytes. A deliberate product
change must update that regression and requalify the affected native boundary.

| Module | Responsibility |
| --- | --- |
| `bindings.cjs` | Canonical bounded record, exact dynamic FD operands, positional input reads and digests |
| `runtime-pack.cjs` | Validate the complete pinned runtime pack and expose only its npm subtree |
| `closed-resolver.cjs` | Resolve/load CJS, ESM and JSON from the captured inventory; no disk fallback or addons |
| `descriptor-bridge.cjs` | Bind stock npm parsing/fetching to exact retained tarballs and their computed integrity |
| `project-config.cjs` | Supply verified-empty content for the one exact project `.npmrc` read |
| `entry.cjs` | Fixed runtime/argv/VFS startup and stock npm CLI entry |

The binding record accepts one to eight statically reviewed local script-free
leaf packages, distinct descriptors 3..255, at most 32MiB per archive and 64MiB
in total, and retained target/cache directory identities. It accepts no caller
argv or external fetch source. The empty user and global config descriptors are
distinct. The SHA512 used by npm comes from the retained artifact bytes.

Project config requires its own routing: stock `--userconfig` and
`--globalconfig` do not disable project `.npmrc`. The pinned config loader uses
lexical path resolution for an explicit CLI prefix and returns before cwd or
workspace discovery. It reads exactly `/proc/self/fd/N/.npmrc` as UTF-8. Only
that read receives empty content; aliases or changed read shapes refuse.
Unexpected physical target objects remain for the native output verifier to
reject. `project-config-source-hashes.json` records the source chain reviewed
for npm 11.19.0. Arborist may separately realpath the target for hidden-lock
package keys; native verification must bind those keys to its retained physical
target identity as well as each descriptor-relative artifact source.

The pure controls establish parsing, boundedness, digest/identity drift,
configuration routing and module resolution behavior. The descriptor controls
execute only three pinned parser/validator source files with unrelated parsing
dependencies replaced by refusal stubs. Resolver controls use synthetic inert
module trees. They do not execute npm install, package code, kernel containment,
ACK protocols or publication; those require separate native tests.
